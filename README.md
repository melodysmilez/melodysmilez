# MelodySmilez

A playful, editorial personal website built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

Most placeholder content lives in `lib/content.ts`.

- Update your Instagram handle and profile URL.
- Replace Spotify playlist URLs and embed URLs.
- Add or edit learning posts.
- Replace remote placeholder images.
- Update contact details.

## Deploy

Push the repository to GitHub, import it into Vercel, and add `melodysmilez.com` in the Vercel project domain settings.
